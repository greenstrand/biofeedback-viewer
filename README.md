# Biofeedback Visualizer

A web-based visualization tool for the Pathway MR-20 dual-channel sEMG device, designed to display muscle activity data in a large, room-visible format.

## Purpose

This is a **supplementary visualization tool** for personal biofeedback monitoring. It is **not intended to replace** the official Telesis diagnostic software or any medical/clinical applications. Always use the manufacturer's approved software for diagnostic purposes.

This application does not transfer data to or from the source computer in any way.

## Requirements

- Pathway MR-20 device connected via USB
- Chromium-based browser (Chrome, Edge, Opera)
- HTTPS connection (provided by GitHub Pages)
